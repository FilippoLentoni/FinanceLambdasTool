# Recursive research MCP adapter

`run_recursive_improvement` delegates to the same-environment FinanceModel classical API and requires producer contract 1.6.0. Request/response schemas come from the pinned shared wheel. The adapter preserves immutable cycle/iteration references and objective-horizon evidence; it does not calculate investment returns or generate attribution narratives.

Omitting `dry_run` or sending `dry_run=true` invokes a read-only producer path. Remote Gateway clients should send `dry_run=true` explicitly to match viewer argument grants. For paid advancement, the pipeline verifies the propagated user token, requires researcher authority and `confirmed_by_user=true`, derives a downstream idempotency key, and retrieves an estimate before any paid call. The estimate must be finite, nonnegative and fit the configured budget category. Ordinary research retains the USD 0.50 CPU hard bound. Only a schema-valid matching Qwen/Jev benchmark proposal may use its sandbox category limit (gpu or cpu_research); strategy, job family and category must agree. The producer additionally enforces applicable weekly/monthly/iteration limits, GPU/vendor approval and no automatic activation.

If preflight returns a running, stopped or proposal-ready cycle, or an existing job awaiting approval, the adapter returns the immutable evidence without requiring a nonexistent estimate or attempting another mutation. The record's historical `dry_run` field does not determine current launchability; state, absence of an existing job and an eligible cost estimate do.

Both the hosted AgentCore graph and direct MCP clients can retrieve cycle evidence with `get_classical_analysis`. Qwen swarm and Jev benchmark readiness is returned by the producer in `benchmark_capabilities`. The hosted graph obtains an exact typed `submit_experiment` dry-run estimate, then confirms advancement through the same recursive cycle so FinanceModel persists the job/result lineage. Independent sandbox submissions retain their own approval and cost rules. Neither this adapter nor its read-only preview launches a GPU job or changes paper holdings.

Public citations are permitted only at validated `sources[i].url` and `evidence[i].sources[j].url` leaves (up to 50 citations per group and 100 evidence groups). HTTP(S), public host/IP, and credential checks reject storage endpoints, private addresses and internal hosts. Citation titles, other metadata and the rest of the evidence remain subject to the storage leak guard. The same checks apply when the retained analysis is retrieved later.
