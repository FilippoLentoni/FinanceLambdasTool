get_etf_research_inputs is a read-only beta reader tool routed to the independent classical
model backend. It requires contract 1.8.0 and symbols (ETF allowlist); optional decision_at,
baseline_analysis_id OR input_snapshot_id, and algorithm request a matched optimizer sensitivity.
The response gives licensed point-in-time features, missingness, source/payment checksums,
PPO vector ordering/training eligibility, and LLM evidence context. Unknown rights/timestamps
are ineligible; no improved performance is claimed. No purchases, secrets, portfolio orders or
production activation are reachable through this tool. See FinanceModel/docs/etf-news-research.md.
